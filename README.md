## 🌟 Highlights & Features

### 🎨 4-Flavor Theme Morphing System
Visitors can dynamically switch the entire visual identity, typography, glowing circuit effects, card styling, and hero packaging artwork between 4 distinct flavors:

1. 🌈 **Neon Hologram**: High-energy cyberpunk arcade with glowing circuit traces, iridescent foil packaging, and electric cyan (`#00F0FF`) / hot pink (`#FF007F`) accents.
2. 🎨 **Street Graffiti**: Urban neo-brutalist pop with spray paint drips, brick textures, and bold contrast shadows.
3. 💎 **Matte Minimal**: Industrial slate precision, frosted glass, and razor-sharp geometric typography.
4. ⚡ **Midnight Gold**: Studio dark signature with obsidian hardware, 24K silicon circuitry, and emerald accents.

## 💻 Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Dynamic CSS Variables + Custom Google Fonts
- **Icons**: Lucide React
- **Effects**: Canvas Confetti, Framer Motion
- **State & Storage**: React Context + LocalStorage persistence

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
