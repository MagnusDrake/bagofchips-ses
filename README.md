## 🌟 Highlights & Features

### 🎨 4-Flavor Theme Morphing System
Visitors can dynamically switch the entire visual identity, typography, glowing circuit effects, card styling, and hero packaging artwork between 4 distinct flavors:

1. 🌈 **Neon Hologram**: High-energy cyberpunk arcade with glowing circuit traces, iridescent foil packaging, and electric cyan (`#00F0FF`) / hot pink (`#FF007F`) accents.
2. 🎨 **Street Graffiti**: Urban neo-brutalist pop with spray paint drips, brick textures, and bold contrast shadows.
3. 💎 **Matte Minimal**: Industrial slate precision, frosted glass, and razor-sharp geometric typography.
4. ⚡ **Midnight Gold**: Studio dark signature with obsidian hardware, 24K silicon circuitry, and emerald accents.

### 🛠️ Interactive Project Configurator ("Chip Builder")
- **Solution Categories**: Web Apps & SaaS, Mobile Apps (iOS/Android), 3D WebGL Games, Custom Software & Automations, AI & RAG Systems.
- **Architectural Modules**: Auth, Database Schema, Stripe Payments, Admin Dashboard, 3D Shaders, Push Notifications, Offline-first Sync, Vector Knowledge Base, and CI/CD DevOps.
- **Sprint Multipliers**: Balanced Standard Sprint, Priority Sprint, or Turbo Crunch Mode.
- **Instant Estimation**: Calculates real-time investment and turnaround weeks, generates an active client ticket with celebratory confetti, and directs clients to the live milestone roadmap.

### 📊 Real-Time Client Hub & Sprint Tracker
- Track active tickets through stages: `Scoping`, `In Active Sprint`, `QA Testing`, `Deployed`.
- Milestone checklist showing live deliverable artifacts (*Figma Prototypes, TestFlight builds, Staging URLs, Architecture Specs*).
- Direct intake form to dispatch new software requests with browser local storage persistence.

### 🚀 Capabilities & Portfolio Showcase
- Filterable case studies with quantitative metrics and *Problem vs. Solution* deep-dive modals.
- Comprehensive tech stack breakdown covering React, Next.js, React Native, Flutter, Three.js, Python, Go, and Docker.

## 💻 Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Dynamic CSS Variables + Custom Google Fonts
- **Icons**: Lucide React
- **Effects**: Canvas Confetti, Framer Motion
- **State & Storage**: React Context + LocalStorage persistence

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
